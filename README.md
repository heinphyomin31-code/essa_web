# Ei Shwe Sin Aung — Portfolio Website

A responsive one-page professional portfolio built with **HTML5, Bootstrap 5, custom CSS and JavaScript**.

## Files

- `index.html` — page content and Bootstrap layout
- `css/style.css` — colors, typography, responsive layout and styling
- `js/script.js` — navbar scroll effect, mobile menu behavior and footer year
- `assets/profile.jpg` — profile photo supplied for this portfolio

## Run locally

Open `index.html` in a browser. An internet connection is needed to load Bootstrap, Bootstrap Icons and Google Fonts from their CDNs.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new repository, for example `ei-shwe-sin-aung-portfolio`.
2. Upload **all files and folders** from this project. Keep the `css`, `js` and `assets` folder structure unchanged.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. The public website URL will appear in the Pages settings.

## Before publishing

- Confirm that the phone number, email address and location are correct and that you want them publicly visible.
- Add dates and more detailed responsibilities to the experience entries if you want to show them; they were not included in the supplied CV.
- The skill bars are decorative visual indicators, not measured proficiency ratings.
